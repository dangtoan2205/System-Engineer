# System-Engineer

## System Engineer là gì?

**System Engineer (Kỹ sư hệ thống)** là người thiết kế, triển khai, quản trị và bảo trì hạ tầng CNTT, đảm bảo hệ thống hoạt động ổn định, an toàn và đáp ứng nhu cầu của doanh nghiệp.

**Nhiệm vụ chính**
- **Thiết kế hệ thống**: Lựa chọn kiến trúc, phần cứng, phần mềm và giải pháp phù hợp.
- **Triển khai hệ thống**: Cài đặt máy chủ, mạng, phần mềm và cấu hình hạ tầng.
- **Quản trị & bảo trì**: Giám sát, xử lý sự cố, cập nhật, nâng cấp và đảm bảo bảo mật hệ thống.
- **Hỗ trợ người dùng**: Hỗ trợ kỹ thuật, hướng dẫn và giải quyết các vấn đề phát sinh.

**Kỹ năng cần có**
- **Kiến thức tổng quan về CNTT**: Hệ điều hành, mạng, máy chủ, phần cứng, ảo hóa, cloud...
- **Kỹ năng xử lý sự cố**: Phân tích nguyên nhân và khắc phục lỗi nhanh, hiệu quả.
- **Kiến thức bảo mật**: Triển khai các biện pháp bảo vệ và xử lý sự cố an ninh.
- **Quản lý dự án**: Lập kế hoạch, triển khai và quản lý tài nguyên.
- **Kỹ năng giao tiếp**: Phối hợp với đồng nghiệp, khách hàng và hỗ trợ người dùng hiệu quả.
